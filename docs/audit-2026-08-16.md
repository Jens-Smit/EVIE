## 2. Neue kritische Befunde

### 2.1 🔴 P0 – Migrationskette bootstrapt keine leere DB
**Problem:** Erste Migration (`Version20260811190100`) beginnt mit `INSERT INTO user_profile...`, aber **keine Migration erstellt die Tabelle** (`grep -rn "CREATE TABLE user_profile" migrations/` → 0 Treffer).

**Fehler bei Ausführung:**
```
[error] Migration DoctrineMigrations\Version20260811190100 failed
SQLSTATE[42P01]: Undefined table: 7 ERROR: relation "user_profile" does not exist
```

**CI-Problem:** Der CI-Job testet **`doctrine:schema:create`** statt **`doctrine:migrations:migrate`** (Kommentar in `.github/workflows/ci.yml` Zeilen 148-153 bestätigt dies).

**Fix:** Initial-Migration mit `CREATE TABLE` für alle Basistabellen erstellen.

---

### 2.2 🟠 P1 – RAG nutzt kein pgvector
**Problem:** `EmbeddingRepository::findSimilar()` lädt **alle Embeddings** eines Typs mit `findBy()` und berechnet Ähnlichkeit in PHP.

**Code:** `src/Repository/EmbeddingRepository.php:36-38`
```php
$candidates = $this->findBy(['contentType' => $contentType]); // ALLE Zeilen!
```

**Beweis:** `grep -rn "pgvector|<->|::vector" src/` → **0 echte Treffer**.

**Fix:** Echte pgvector-Operatoren (`<->`, `<=>`) in SQL-Queries nutzen.

---

### 2.3 🟠 P1 – WorkflowOrchestrator: 5 undefinierte Methoden
**Problem:** Klasse ist über `BriefingController` HTTP-erreichbar, enthält aber Aufrufe nicht existierender Methoden:

```
ContextInjector::injectForSystemPrompt()
ToolDefinitionGenerator::generateFromRequest()
DynamicToolFactory::createFromDefinition()
ToolExecutionResult::getError()
DynamicTool::getDefinition()
```

**Beweis:** PHPStan-Baseline enthält diese 5 Fehler; **kein Test** deckt die Klasse ab (`grep -rln "WorkflowOrchestrator" tests/` → 0 Treffer).

**Fix:** Methoden implementieren oder Aufrufe entfernen.

---

### 2.4 🟡 P2 – PgVectorStore: Toter Code mit MySQL-Syntax
**Problem:** `src/Infrastructure/VectorStore/PgVectorStore.php` nutzt `ORDER BY RAND()` (MySQL) statt `RANDOM()` (Postgres). Wird **nirgends** konsumiert.

**Fix:** Entweder korrigieren und anbinden oder löschen.

---

### 2.5 🟡 P2 – Golden-Path-Test unvollständig
**Problem:** `EvolutionGoldenPathTest.php` testet **kein HTTP-Layer** (`KernelTestCase` statt `WebTestCase`) und **keine Tool-Ausführung**.

**Fix:** Test auf `WebTestCase` umstellen und Tool-Ausführung hinzufügen.

---

### 2.6 🟢 P3 – StoreRetrieverAdapter: Toter Code
**Problem:** Wird **nirgends** verwendet, trotz Aussage in `roadmap-progress.md`.

**Fix:** Löschen oder korrekt anbinden.

---

### 2.7 🟢 P3 – docker-compose.prod.yml: Unsicheres Default-Passwort
**Problem:** `${POSTGRES_PASSWORD:-evie_password}` (Default im Repo sichtbar).

**Fix:** Auf `${POSTGRES_PASSWORD:?...}` ändern (harter Fehlschlag wenn nicht gesetzt).
